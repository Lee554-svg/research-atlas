# 연구트리 아카이브

230개 연구, 4개 학문, 26개 시대별 세부 분야, 95개 해금 조건 묶음을 포함한 정적 연구 지도입니다. HTML/CSS/JavaScript만 사용하며 외부 라이브러리, 서버, 계정, 추적 코드, 인터넷 폰트 의존성이 없습니다.

## 실행

`dist/index.html`을 브라우저로 열면 됩니다. 로컬 파일 실행도 지원합니다.

HTTP 미리보기: 프로젝트 폴더에서 `python3 -m http.server 8080 --directory dist` 실행 후 http://localhost:8080 접속.

## GitHub Pages

`dist` 안의 모든 파일을 GitHub Pages 게시 폴더에 그대로 넣으세요. 상대 경로만 사용하므로 `사용자.github.io/저장소/` 하위 경로를 지원합니다. 빌드 과정과 환경 변수는 필요하지 않습니다. Sites용 `.openai` 폴더는 GitHub Pages에 불필요합니다.

## 조작

- 마우스 드래그 / 한 손가락 이동. 이동 중에는 노드 선택이 취소됩니다.
- 휠 / 두 손가락 핀치: 포인터 또는 두 손가락 중심을 기준으로 확대축소.
- 하단 +, −, 전체 지도, 중심 이동. 전체 지도는 구조 탐색용 축소 화면입니다.
- 학문 버튼으로 이동. 중심 노드와 세부 분야 노드도 클릭하여 시작 연구를 탐색할 수 있습니다.
- 연구명 검색. 노드 선택 시 데스크톱 우측 패널 / 모바일 하단 카드.
- 상세 정보의 선행·후속·조건 연구 버튼으로 해당 연구에 이동.
- 데스크톱: 시대 필터, 전체 조건 연결선 표시. 모바일에서도 선택한 연구의 조건 연결선은 표시됩니다.
- 방향키 이동, +/− 확대축소, Home 중심, / 검색, Escape 닫기.

## 데이터 수정

원본은 `dist/research-data.json`입니다. 수정 후 `node scripts/sync-data.mjs`를 실행하면 ID/참조/경로 순환을 검사하고 브라우저에서 사용하는 `dist/data.js`를 생성합니다. 사이트 UI 코드 수정은 필요하지 않습니다.

각 연구: `id`, `name`, `field`, `era`, `category`, `group`, `tier`, `tierSource`, `effects`, `prerequisites`(연구 ID 배열), `conditions`(원문 조건 배열), `notes`. 고유 ID는 이름을 바꾸더라도 유지하세요. `effects`는 문자열 또는 null입니다.

`conditionLinks`는 연구 완료 조건의 별도 관계입니다. `type: condition`은 일반 조건, `type: or`는 선택 조건입니다. `prerequisites`는 원문 연구 경로로, 게임에서의 논리 AND/OR를 임의로 단정하지 않습니다.

분야/시대/세부 분류를 추가하려면 `groups`에 새 분류를 추가하고 연구의 `group`에 ID를 연결하세요. `roots`는 원본 기록이며 화면의 시작 연구는 선행 관계로 자동 계산합니다.

## 자료 해석

- 사용자 지시에 따라 명백한 오타를 교정했습니다. `originalName`, `originalConditions`에 기존 표기를 보존합니다.
- 연구 효과 225개 노드 반영. 효과 없음, 미공개, 자료 미제공을 구분합니다. 조건 미제공은 미정이며 ‘조건 없음’으로 단정하지 않습니다.
- 효과 자료의 선박 항목은 기존 기술학/선박 분류를 유지합니다. ‘전투용 복엽기’의 효과는 기존 ‘전투용 단엽기’에 임시 대응하고 명칭 차이를 상세 정보에 기록합니다.
- 효과가 여러 개인 연구는 줄을 나누어 표시합니다. 수치 미공개 효과는 임의의 수치를 추가하지 않습니다.
- 원문에 명시된 3/4/5티어는 해당 값 사용. 나머지는 경로 순서로 추정하고 UI에 ‘경로 추정’으로 표시합니다.
- 원문의 분기 들여쓰기는 일부 모호합니다. 추정한 연결은 세부 패널의 확인 사항과 점선으로 표시합니다.
- `마력과의 교감`은 원문 세부 분야별로 구분했습니다. 동명 합류(상업화폐 개발, 이상향의 확립, 아직도 부족한 산출량)는 잠정적으로 단일 노드이며 AND/OR 미확정입니다.
- 산업혁명의 `국가산업 기반 확보` 조건은 연구 목록에 없어 원문 조건으로 남겼습니다. `군수산업 기반 확보`와 동일한지 확인이 필요합니다.
- 연구 진행, 완료 처리, 잠금 상태는 구현하지 않았습니다.

## 렌더링과 호환성

SVG 노드와 곡선, Pointer Events 사용. 프레임당 단일 transform 적용, 뷰포트 바깥 노드 렌더링 제외, requestAnimationFrame으로 입력 병합. 모바일 safe-area와 동적 뷰포트 높이, 회전 크기 변경을 처리합니다.

브라우저 UI에서 데스크톱/모바일 크기, 검색, 상세 열기·닫기, 노드 클릭, 드래그 오선택 방지, 휠 확대를 확인했습니다. 실제 iPhone Safari/Chrome 기기에서의 두 손가락 핀치 및 회전은 별도 실기기 확인이 필요합니다.
